# 검색 평가 결과 요약

31개 PDF의 텍스트 근거 질문 101개로 Dense, Hybrid(DBSF), Hybrid(RRF), RRF + Cohere 리랭킹을 비교했다. 아래 수치는 **직접 확인한 정답 근거 청크 ID**가 검색 결과의 몇 위에 놓였는지를 기준으로 한다.

| 검색 방식 | Hit@1 | Hit@5 | MRR@10 | 확인한 근거 Recall@5* | Precision@5 하한* | nDCG@5* |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Dense | 67.3% | 93.1% | 0.779 | 0.909 | 0.196 | 0.804 |
| Hybrid(DBSF) | 76.2% | 93.1% | 0.837 | 0.904 | 0.194 | 0.833 |
| Hybrid(RRF) | 74.3% | 98.0% | 0.843 | 0.954 | 0.204 | 0.857 |
| RRF + Cohere 리랭킹 | **92.1%** | **100%** | **0.959** | **0.992** | **0.216** | **0.962** |

RRF는 DBSF보다 1위 적중률은 약간 낮았지만, 상위 5개 안에서 확인한 근거를 더 자주 찾았다(98.0% vs 93.1%). 리랭킹을 거치자 Hit@1은 **74.3% → 92.1%(+17.8%p)**로 올랐다. 다만 리랭킹 때문에 정답 근거가 1위에서 밀린 질문도 2개 있었다.

| 측정 구간 | p50 | p95 |
| --- | ---: | ---: |
| 질문 임베딩 | 237.49 ms | 355.89 ms |
| Dense 검색 | 14.21 ms | 18.38 ms |
| DBSF 검색 | 29.23 ms | 34.55 ms |
| RRF 검색 | 22.04 ms | 24.15 ms |
| Cohere 리랭킹 | **1,494.77 ms** | **1,767.18 ms** |

검색 자체는 수십 ms였지만, 리랭킹 API 호출은 p50 약 1.5초가 걸렸다. 이 시간은 **구간별 단일 실행 측정값**이며, 실제 서비스 요청의 종단 간 응답 시간이나 동시 부하 성능을 뜻하지 않는다.

\* 질문마다 확인한 근거만 라벨링했으므로 Recall은 **확인한 근거 기준**, Precision은 **하한값**, nDCG는 **확인한 근거만 관련으로 본 이진 잠정값**이다. 전체 관련 청크를 판정한 최종 지표나 Chat 답변 품질로 해석하면 안 된다.
